# Obsidian Embeds Reference

## Note Embeds

```markdown
![[Note Name]]
![[Note Name#Heading]]
![[Note Name#^block-id]]
```

Use a block ID by appending `^block-id` to a paragraph, or on a separate line after a list or quote block.

## Image Embeds

```markdown
![[image.png]]
![[image.png|640x480]]
![[image.png|300]]
```

## External Images

```markdown
![Alt text](https://example.com/image.png)
![Alt text|300](https://example.com/image.png)
```

## Media and PDF Embeds

```markdown
![[audio.mp3]]
![[audio.ogg]]
![[video.mp4]]
![[document.pdf]]
![[document.pdf#page=3]]
![[document.pdf#height=400]]
```

## Query Embeds

````markdown
```query
tag:#project status:done
```
````
